# Meta-Graph-API-FastAPI-Demo
A hands-on backend project built to learn the Meta (Facebook) Graph API, Instagram Business API, and FastAPI through a real-world software engineering workflow

The project demonstrates how modern SaaS applications integrate with Meta's developer platform to authenticate users, communicate with Instagram/Facebook services, receive webhook events, and expose RESTful API endpoints.

Developed as part of my onboarding into an AI startup, this project serves as a learning environment for understanding the architecture behind social commerce platforms before contributing to a production codebase.
